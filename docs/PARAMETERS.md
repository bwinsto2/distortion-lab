# Parameter reference

Generated by `tools/param_table.py` from `shared/parameters.json`. Ranges are interface bounds, not physiological bounds.
`step` is the fine slider step and the quantisation grid (values snap to `min + k*step`); `coarse` is the coarse slider step;
`proposal` is the base displacement used for coarse alternatives (fine = 0.25x; each repeat multiplies by the shrink factor, default 0.6).

## semantic-grating 1.0.0

Explicit deterministic appearance generator: one carrier grating with documented coordinate displacements (bend, zigzag/step, offset), interruption, crossing pattern and gap mask. Not part of the Olianezhad et al. synthesis model.

## legacy-rectified 1.0.0

Backward-compatible implementation of the original prototype: summed rectified gratings, Olianezhad et al. 2025 Eqs. 1-2 image-synthesis family with explicit final clip ±1 and direct (unnormalized) weights.

Paths: `contrast`, and `c<ID>.<field>` for component ID (e.g. `c3.weight`, `c3.enabled`). Up to 12 components.

| field | JSON key | range | step | coarse | proposal | notes |
|---|---|---|---|---|---|---|
| Output contrast | `contrast` | 0 … 1 | 0.01 | 0.05 | 0.1 |  |
| Orientation θ | `orientation` | 0 … 180 | 0.1 | 1 | 3 |  |
| Spatial frequency f | `frequency` | 0.1 … 24 | 0.01 | 0.1 | 0.2 |  |
| Phase φ | `phase` | 0 … 360 | 1 | 10 | 20 |  |
| Light/dark balance K | `duty` | -1 … 1 | 0.01 | 0.05 | 0.1 |  |
| Component clipping T | `threshold` | 0 … 2 | 0.01 | 0.05 | 0.1 |  |
| Component weight W | `weight` | 0 … 20 | 0.01 | 0.1 | 0.5 | relative 0.15×|value| if larger |

## Gallery templates

Gallery templates are overrides of the semantic generator relative to the current reference grating (orientation, frequency, phase, contrast are copied from the reference). They are deterministic illustrative appearances, not validated percept categories.
