# Distortion Lab cloud starter

This package contains the existing working application source as well as the complete specification for the next version. Extend and reuse the existing code where useful rather than rebuilding everything.

1. Read BUILD-SPECIFICATION.md for the requested next version and acceptance checks.
2. Open existing-prototype/distortion-lab-presets.html to inspect the working version. It is a self-contained HTML/CSS/JavaScript application.
3. Reuse its tested math-core, preset data, rendering conventions, optical layout controls, JSON loading/export, and other applicable code. Refactor as necessary to add semantic controls, comparisons, undo/redo, pins, mixtures, autosaving and a Python backend.
4. existing-prototype/preset-library.json contains all ten exact existing presets; presets/ contains individual loadable sessions; images/ and barrett-inspired-gallery.png show the saved outputs.
5. Read existing-prototype/README.md and VALIDATION.txt for provenance, limitations, and checks actually performed. Those checks apply to the existing version only.

The existing prototype does not yet contain the newly requested semantic matching workflow or an AI connection. Build those additions, test them, and deliver a complete runnable package. No original Mac paths, local server, Library search, or outside conversation are needed.

Suggested cloud task request:

“Unpack this starter, read START-HERE.md and BUILD-SPECIFICATION.md, extend the included existing prototype, implement the requested application completely, test it, and deliver the runnable package.”
