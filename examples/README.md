# Examples (all synthetic)

- `synthetic-session.json`: a `distortion-lab/session/2` session from `tools/make_examples.js`. It shows a combination
  choice, a pin, seeded alternatives (chosen and kept), a coalesced slider edit, a description with a marked region,
  an accepted record and an outcome. **Not participant data.** Open it via Experimenter → Open / import JSON.
- `semantic-gallery.json`: every semantic gallery tile for the default reference (90°, 4 c/°) as reusable reconstructions.
- `images/`: 256 px PNGs of representative forms, rendered by the Python reference renderer (`tools/render_examples.py`).
- `semantic-contact-sheet.png`: an overview of those images.
- The ten original-prototype preset sessions and images are in `../existing-prototype/presets` and `../existing-prototype/images`.
